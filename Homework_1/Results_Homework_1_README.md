## 4. Описание выполненной работы

- **Номер занятия:** 1
- **Текст задания:** 
1. Написать код для каждого из этих классов 
2. (Задача Лидера рабочей группы) Написать простую компоновку для этих классов (создать Профиль Пользователя, наполнить его данными) для демонстрации возможности работы этих классов друг с другом. 
3. Написать простой "сервисный" класс, с помощью которого можно создавать профили, вносить в них изменения, получать краткую статистику профиля (с использованием деконструкторов). (Или реализовать подобный функционал на уровне точки входа в приложение.) 
4. Записать проблемы, с которыми пришлось столкнуться во время работы над задачами. Сформулировать вопросы.

### Что сделано

- Каждый участник написал свой класс: `User`, `CommunicationChannel`, `Contact`, `UserProfile`.

### Назначение классов

- **User** (Viva): Id, ФИО, логин, хэш пароля. Хэш принимается готовым. Деконструктор возвращает Id, ФИО и логин.
- **CommunicationChannel** (Viva): Id и название канала. Неизменяемый.
- **Contact** (Matvey): Id, Id канала и идентификатор в канале. Равенство по Id.
- **UserProfile** (Viola): пользователь и коллекция контактов. Не допускает дубль по Id, удаляет контакт по Id.
- **UserService** (Lead): сервисный слой над классами.
- **Program** (Lead): демонстрация компоновки, работы сервиса и ошибок.

### Запуск

Из папки `Homework_1`:
	dotnet build -p:TreatWarningsAsErrors=true
	dotnet run
Требуется .NET 8 SDK.
