# Структуры
**Структура** (`struct`) — это **значимый тип**, который, как и класс, объединяет **поля** и **методы**.

Отличия, которые нужно запомнить сразу:
- структура **копируется целиком** при присваивании и передаче в метод;
- структура **не может наследоваться** от класса и не может быть базой для другой структуры;
- у структуры **нет** ссылки на объект в куче — сама переменная **и есть** значение.

Структура хорошо подходит для **небольших** наборов данных без собственной «жизни»: оценки, координаты, денежная сумма, номер аудитории.

**Примеры из жизни:** 
`Point` / `Vector2` 
`DateTime` и `TimeSpan`
`Span<T>` и `ReadOnlySpan<T>`

**Вопрос для закрепления:** чем студенческий билет отличается от студента — почему билет удобно сделать структурой, а студента классом?

## Определение структуры и создание объекта структуры

```cs
// Студенческий билет (значимый тип: это просто набор характеристик)
struct StudentCard
{
    // Поля структуры
    public string? Number;  // номер билета (null у структуры по умолчанию)
    public int Course;      // курс обучения
    public bool IsValid;    // действителен ли билет

    // Конструктор структуры обязан присвоить значения ВСЕМ полям
    public StudentCard(string number, int course)
    {
        Number = number;
        Course = course;
        IsValid = true;
    }

    // Метод структуры
    public string Describe() =>
        $"билет {Number}, {Course} курс, " + (IsValid ? "действителен" : "недействителен");
}
```

Объект структуры создаётся так же, как объект класса:

```cs
StudentCard card = new StudentCard("Б-2417", 2);
Console.WriteLine(card.Describe());
```

**Вопрос для закрепления:** чем описание структуры отличается от описания класса, которое мы делали на прошлом занятии?

## Инициация полей по умолчанию

Если конструктор не вызывается явно, структура получает **все поля со значениями по умолчанию** своего типа: `0`, `false`, `null`, `default` для вложенных структур.

```cs
StudentCard empty = new StudentCard();   // все поля обнулены
StudentCard alsoEmpty = default;         // то же самое

// Number == null, Course == 0, IsValid == false
Console.WriteLine(empty.Describe());
```

Для класса такого «бесплатного» состояния с корректными значениями нет: там поля инициализируются либо в конструкторе, либо значениями по умолчанию, но объект всё равно нужно создать через `new`.

**Вопрос для закрепления:** какие значения получат поля структуры `StudentCard`, созданной выражением `default`?

## Конструкторы структуры

В структуре можно объявлять конструкторы **с параметрами**. В C# 10+ разрешён и **конструктор без параметров**, но тогда он обязан инициализировать все поля.

```cs
struct Auditorium
{
    public string Number;
    public int Seats;

    // Конструктор без параметров (C# 10+)
    public Auditorium()
    {
        Number = "не назначена";
        Seats = 0;
    }

    // Конструктор с параметрами
    public Auditorium(string number, int seats)
    {
        Number = number;
        Seats = seats;
    }
}
```

Цепочка конструкторов через `: this(...)` работает так же, как у классов.

**Вопрос для закрепления:** почему компилятор не позволит конструктору структуры закончиться, не присвоив значения какому-либо полю?

## Копирование структуры

При присваивании **копируются все поля**. Дальше оригинал и копия живут независимо.

```cs
StudentCard original = new StudentCard("Б-2417", 2);
StudentCard copy = original;          // копия всех полей
copy.Course = 3;                      // меняем только копию

Console.WriteLine(original.Course);   // 2 — оригинал не изменился
Console.WriteLine(copy.Course);       // 3
```

С C# 10 для структуры доступно выражение `with`, которое создаёт копию с изменёнными полями:

```cs
StudentCard moved = original with { Course = 3, IsValid = false };
```

**Вопрос для закрепления:** изменится ли `original`, если после `StudentCard copy = original;` выполнить `copy.Number = "Б-0000";`?

# Типы значений и ссылочные типы

|                       | **Тип значения** (`struct`, `int`, `bool`, `DateTime`)      | **Ссылочный тип** (`class`, `string`, массивы) |
| --------------------- | ----------------------------------------------------------- | ---------------------------------------------- |
| Что хранит переменная | само значение                                               | **ссылку** на объект                           |
| Где живёт             | стек (для локальных переменных) или внутри другого значения | управляемая куча                               |
| Копирование           | копируется значение                                         | копируется ссылка                              |
| Значение по умолчанию | `0`, `false`, нулевая структура                             | `null`                                         |
| Наследование          | нет                                                         | есть                                           |

```cs
// Ссылочный тип: копируется ссылка на один и тот же объект
Student student = new Student("Иван", 19);
Student same = student;
same.SetAge(20);

Console.WriteLine(student.GetAge());  // 20 — это тот же самый объект
```

## Хранение типов в памяти: стек и куча, сборка мусора

- **Стек** — быстрая область памяти, где лежат локальные переменные и параметры методов. Значение исчезает автоматически, когда метод завершается.
- **Куча** — область, где лежат объекты классов. Объект живёт, пока на него есть хотя бы одна ссылка.
- **Сборщик мусора (GC)** освобождает объекты в куче, на которые больше никто не ссылается. Работает поколениями (0, 1, 2), вручную вызывать его в обычном коде не нужно.

```cs
static void Demo()
{
    StudentCard card = new StudentCard("Б-2417", 2);   // значение в стеке
    Student student = new Student("Иван", 19);          // объект в куче, ссылка в стеке
}
// После выхода из метода card исчезает вместе со стеком,
// а объект student станет «мусором» и будет удалён сборщиком.
```

**Вопрос для закрепления:** что случится с объектом в куче, если единственная ссылка на него вышла из области видимости?

## Составные типы

Составной тип — это тип, который содержит другие типы:

```cs
// Структура внутри структуры
struct ExamRecord
{
    public string Subject;      // ссылочный тип внутри значения
    public int Mark;            // значение
    public DateTime Date;       // значение (структура)
}

// Значение внутри класса
class StudentProfile
{
    public string Name;
    public StudentCard Card;    // структура внутри ссылочного типа
}
```

## Копирование значений

Правило простое: **копируется то, что лежит в переменной**.

- у типа значения в переменной лежит **значение** → копируется значение;
- у ссылочного типа в переменной лежит **ссылка** → копируется ссылка.

```cs
StudentCard cardA = new StudentCard("Б-2417", 2);
StudentCard cardB = cardA;      // полная копия

Student studentA = new Student("Анна", 20);
Student studentB = studentA;    // копия ссылки
```

**Вопрос для закрепления:** сколько объектов в куче появится после выполнения двух строк выше?

## Ссылочные типы внутри типов значений

Структура может содержать ссылку. Копирование структуры копирует **ссылку**, а не объект за ней.

```cs
struct DormPlace
{
    public string Room;
    public Student? Occupant;   // ссылка на объект студента
}

var place = new DormPlace { Room = "412", Occupant = new Student("Иван", 19) };
var placeCopy = place;          // Room скопирован, Occupant — та же ссылка

placeCopy.Room = "501";         // оригинал не изменился
placeCopy.Occupant!.SetAge(20); // изменился ОБЩИЙ студент
```

**Вопрос для закрепления:** почему изменение `Room` в копии не видно в оригинале, а изменение `Occupant` — видно?

## Объекты как параметры методов

В метод объект класса передаётся **по ссылке**, структура — **по значению**.

```cs
// Изменяет исходный объект: передана ссылка
private static void RenameStudent(Student student)
{
    student.SetName("Пётр");
}

// Изменяет только локальную копию: передано значение
private static void ReissueCard(StudentCard card)
{
    card.Number = "Б-0000";
}
```

Если значение структуры нужно изменить в методе, используют `ref`. Если структуру нужно передать **без копирования, но только для чтения** — `in`.

```cs
private static void MoveToCourse(ref StudentCard card, int course)
{
    card.Course = course;
}
```

**Вопрос для закрепления:** как передать структуру в метод, чтобы изменения сохранились в вызывающем коде?

# Область видимости переменных и констант

**Область видимости** — часть кода, в которой имя доступно.

- **Локальная переменная** видна от объявления до конца блока `{ ... }`, в котором объявлена.
- **Поле класса** видно во всех методах этого класса.
- **Константа** (`const`) видна в пределах своей области видимости и должна быть известна на этапе компиляции.

```cs
class Journal
{
    private const int MaxMark = 5;   // константа уровня класса

    public void Print()
    {
        int count = 0;               // видна до конца метода

        if (count == 0)
        {
            int local = 42;          // видна только внутри if
            Console.WriteLine(local + MaxMark);
        }

        // Console.WriteLine(local); // ошибка: local здесь уже не существует
    }
}
```

Одноимённые переменные во вложенном блоке **затеняют** внешние — это разрешено, но легко запутаться, поэтому лучше не делать.

**Вопрос для закрепления:** видна ли переменная, объявленная внутри блока `if`, после закрывающей скобки этого блока?

# Пространства имён

**Пространство имён** — это «папка» для типов, которая позволяет:
- группировать родственные типы;
- избегать конфликтов имён (`University.Student` и `Dormitory.Student`);
- управлять видимостью типов.

```cs
namespace University.Journal
{
    class Mark
    {
        public int Value;
    }
}
```

## Класс Program и метод Main

Классическая точка входа — **статический метод `Main`** в классе `Program`.

```cs
namespace University;

class Program
{
    static void Main()
    {
        Console.WriteLine("Расписание на день:");
    }
}
```

## Программы верхнего уровня

С C# 9 можно писать код **без класса `Program` и без `Main`**: компилятор создаст их сам.

```cs
// Program.cs — весь файл является телом метода Main
Console.WriteLine("Расписание на день:");
```

## Подключение пространства имён

```cs
using University.Journal;          // подключаем типы пространства имён
using Dorm = University.Dormitory; // псевдоним

var mark = new Mark { Value = 5 };
```

## Вложенные пространства имён

Пространства имён можно вкладывать друг в друга — как каталоги.

```cs
namespace University
{
    namespace Dormitory
    {
        class Room { }
    }
}
```

## Пространства имён уровня файла

С C# 10 пространство имён можно объявить **одной строкой на весь файл**:

```cs
namespace University.Dormitory;   // действует для всего файла

class Room { }
```

## Глобальное пространство имён

Типы без объявленного пространства имён попадают в **глобальное** пространство имён — они видны везде, но с ними легко устроить конфликт.

```cs
class GlobalHelper   // глобальное пространство имён
{
}
```

## Подключение пространства имён по умолчанию

Начиная с .NET 6 в проекте включены **неявные `using`** (`ImplicitUsings`): `System`, `System.Collections.Generic`, `System.Linq` и ещё несколько подключаются автоматически. Кроме этого, можно объявить собственные глобальные `using`:

```cs
// GlobalUsings.cs
global using System.Text;   // действует во всех файлах проекта
```

    - структура копируется целиком при присваивании и передаче в метод;
    - структура не может наследоваться от класса и не может быть базой для другой структуры;
    - у структуры нет ссылки на объект в куче — сама переменная и есть значение.

        Topic("Структуры C#");

        Console.WriteLine(card.Describe());

        // структура получает все поля со значениями по умолчанию
        // для их типа: 0, false, null, default для вложенных структур.
        StudentCard empty = new StudentCard();   // все поля обнулены
        StudentCard alsoEmpty = default;         // то же самое

        Console.WriteLine(empty.Describe());
        Console.WriteLine(alsoEmpty.Describe());

        Console.WriteLine(auditorium.Describe());

        auditorium = default;

        auditorium = new Auditorium("A 42");
        Console.WriteLine(auditorium);

        Console.WriteLine(student.GetAge());

struct StudentCard
{

    public string? Number;  // номер билета (null у структуры по умолчанию)

        IsValid = true;
    }

    // Метод структуры
