# Модели Viva

`Product`, `ProductPosition`, `UserBasket` и `CalculatedPrice` находятся в пространстве имен `Marketplace`. Сохранены исходные названия классов и конструкторов. Используются файловые пространства имен и короткие выражения для простых методов и свойств.

- Деньги и множители скидки имеют тип `decimal`.
- `UserBasket.CalculatePrice(products, discountMultiplier)` возвращает неизменяемую расчетную цену; методы `GetFinalPrice` и `GetDiscountAmount` возвращают итог и скидку в деньгах.
- Множитель `0.95m` означает скидку 5%. Для 3 тарелок по 1000 УЕ и 2 наборов приборов по 2000 УЕ расчет дает: исходная цена 7000, скидка 350, итог 6650.
- Корзина копирует позиции при добавлении и чтении. `RemovePosition` удаляет позицию по ID, `Clear` очищает корзину после успешной оплаты.
- Ошибки расчета и неверные входные данные не меняют содержимое корзины.
- `default(CalculatedPrice)` — нулевая стоимость без скидки.

Профиль пользователя теперь использует эти модели напрямую. Инструкция сборки, сценарии интеграции и ограничения описаны в [общем README](../README.md). Проверки находятся в `../Tests`.
